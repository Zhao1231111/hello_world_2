LIV-Surfel 提出了一种面向（增量式）激光雷达—惯性—视觉 2D Gaussian Splatting 的前馈初始化策略。该方法利用深度与法向先验，并通过后续优化得到的 surfel 进行自蒸馏。实验结果表明，与所选的增量式 GS 基线方法相比，该方法能够改善渲染效果，并实现更快的早期收敛。

三位专家审稿人均认为，解决增量式 GS 中的这些问题具有现实意义。论文中的流水线设计，包括几何约束、时序上下文以及自蒸馏，都具有充分的动机，实验结果的呈现也较为清晰。论文内容符合 RA-L 的范围与定位。

然而，审稿人指出了若干问题，使得该论文目前尚未达到可发表的状态，主要包括：

1. **效率方面的论断。**
   论文将其贡献定位于提升效率，但目前缺乏充分的实验依据来支持这一点。因此，目前尚不清楚该初始化策略带来的收益能否抵消 SPNet、DA3 等模块所引入的额外计算开销。若能提供端到端以及各模块的运行时间、FPS、内存消耗、参数量，以及地图规模增长方面的分析，将有助于支撑这一论断。

2. **对几何能力的表述存在过度宣称。**
   论文声称方法具备“几何感知（geometry-aware）”能力，但当前实验主要关注渲染指标。为了支撑这一论断，需要针对深度、法向和表面几何的精度进行评估。

3. **消融实验有限。**
   目前缺乏足够的实验分析来验证各个流水线组件的合理性。需要在多个序列上增加针对回归器本身、几何条件信息、时序信息/交叉注意力等模块的实验，以获得更具一般性的分析结论。

4. **设计选择需要进一步解释。**
   4a. 当前同时使用 SPNet、DA3 和 LiDAR 的方式存在一定冗余，其必要性尚不清楚。论文需要解释为什么必须同时使用两个深度网络以及额外的 LiDAR。可以通过实验考察更简单的替代方案，例如其他深度/法向估计器、对 DA3 进行尺度恢复，以及减少传感器输入等，以支持当前设计选择。
   4b. 当前所选择的几何先验也需要相对于其他可能的设计选择加以论证，例如曲率、平面度等。

5. **鲁棒性。**
   5a. 论文缺少对于漂移或地图误差可能对自蒸馏过程造成偏差这一问题的讨论或评估。
   5b. 当前初始化策略究竟只是加快了收敛速度，还是也能够改善最终收敛结果？这一点需要通过实验验证。

6. **次要问题。**
   需要增加对失败案例和方法局限性的明确讨论，同时解决审稿人提出的引用错误、术语使用等次要问题。

论文提出了一个有趣的方法，但仍需要进行修改。审稿人认为，目前的实验还不足以充分支撑论文中的全部论断和设计选择。副编辑同意这一判断，并认为上述问题可以通过一次**（大幅度的）修改（major revision）**加以解决，之后论文需要进入第二轮审稿。
